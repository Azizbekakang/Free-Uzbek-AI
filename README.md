# 🦙 Free Llama 3 Uzbek AI Assistant

A clean, responsive, and lightweight web application built with pure HTML, CSS, and JavaScript. It uses Meta's **Llama 3.2** model via Hugging Face's open inference API to provide intelligent AI chat assistance in **Uzbek** without requiring any registration or API keys.

---

## ✨ Features

* 🚀 **Zero Setup / No API Key:** Directly connects to Hugging Face's open inference endpoint.
* 🇺🇿 **Uzbek Language Optimization:** System prompts pre-configured for fluent Uzbek responses.
* 🌙 **Modern Dark Theme:** Sleek UI styled with custom CSS variables.
* 📱 **Fully Responsive:** Smooth layout across desktop, tablet, and mobile devices.
* ⚡ **Pure Vanilla JS:** No frameworks, external dependencies, or build tools required.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Model:** Meta Llama 3.2 1B Instruct
* **API Engine:** Hugging Face Serverless Inference API
* **Deployment:** GitHub Pages
